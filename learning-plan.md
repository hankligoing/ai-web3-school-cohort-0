# 12-Week Learning Plan / 12周学习计划

> Based on: AI/Web3 beginner, 2–3h/day, bilingual output
> 参考：AI/Web3 新手，每日2-3小时，双语输出

---

## Phase 1: AI Foundation (Weeks 1–4)

### Week 1 — LLM & Prompt / 大语言模型与提示词
- [ ] [LLM](https://aiweb3.school/zh/handbook/ai/llm/): What LLMs can and cannot do
- [ ] [Prompt](https://aiweb3.school/zh/handbook/ai/prompt/): How to write clear task goals, boundaries, output formats
- [ ] Practice: Write 3 prompts for common tasks

### Week 2 — Context & RAG / 上下文与检索增强生成
- [ ] [Context](https://aiweb3.school/zh/handbook/ai/context/): What the model sees, what info is trustworthy, what expires
- [ ] [RAG](https://aiweb3.school/zh/handbook/ai/rag/): How to connect external knowledge/sources to the model
- [ ] Practice: Build a simple local RAG pipeline

### Week 3 — Agent & Tool Use / 智能体与工具调用
- [ ] [Agent](https://aiweb3.school/zh/handbook/ai/agent/): How to enable multi-step execution and tool calling
- [ ] [Frameworks](https://aiweb3.school/zh/handbook/ai/frameworks/): LangChain, LangGraph, Agents SDK — what each layer solves
- [ ] Practice: Run a simple agent loop with tool calls

### Week 4 — MCP & Evaluation / 模型上下文协议与评估
- [ ] [MCP](https://aiweb3.school/zh/handbook/ai/mcp/): How models, tools, and context connect via protocol
- [ ] [Evaluation](https://aiweb3.school/zh/handbook/ai/evaluation/): How to test, replay, and improve agent outputs
- [ ] Review & Summary: Build a personal AI concept map

---

## Phase 2: Web3 Foundation (Weeks 5–8)

### Week 5 — Cryptography & Wallet / 密码学与钱包
- [ ] [Cryptography](https://aiweb3.school/zh/handbook/web3/cryptography/): Hash, public/private key, signature concepts
- [ ] [Wallet](https://aiweb3.school/zh/handbook/web3/wallet/): Wallet as identity and signing entry point
- [ ] Practice: Set up a MetaMask wallet, understand seed phrase security

### Week 6 — Smart Contract / 智能合约
- [ ] [Smart Contract](https://aiweb3.school/zh/handbook/web3/smart-contract/): How to deploy, call, and update on-chain state
- [ ] [Dev Stack](https://aiweb3.school/zh/handbook/web3/dev-stack/): Development stack overview
- [ ] Practice: Read and understand a simple Solidity contract

### Week 7 — Account Abstraction & DeFi / 账户抽象与 DeFi
- [ ] [Account Abstraction](https://aiweb3.school/zh/handbook/web3/account-abstraction/): Why Smart Account fits Agent permission models
- [ ] [DeFi](https://aiweb3.school/zh/handbook/web3/defi/): Asset, liquidity, lending, and risk in open financial protocols
- [ ] [Oracle](https://aiweb3.school/zh/handbook/web3/oracle/): How off-chain data enters on-chain systems

### Week 8 — Indexing & Security / 索引与安全
- [ ] [Indexing](https://aiweb3.school/zh/handbook/web3/indexing/): Turn on-chain events into AI-usable data
- [ ] [Security](https://aiweb3.school/zh/handbook/web3/security/): Risk boundaries in contracts, permissions, simulation, monitoring
- [ ] Review & Summary: Map Web3 concept relationships

---

## Phase 3: AI × Web3 Bridge (Weeks 9–10)

### Week 9 — Chain Context & Web3 Tool Use / 链上上下文与工具调用
- [ ] [Chain-aware Context](https://aiweb3.school/zh/handbook/bridge/chain-aware-context/): How on-chain state enters agent context
- [ ] [Web3 Tool Use](https://aiweb3.school/zh/handbook/bridge/web3-tool-use/): How RPC, wallet, and contract tools are called by agents
- [ ] [Agent Workflow](https://aiweb3.school/zh/handbook/bridge/agent-workflow/): Which steps to automate, which need human-in-the-loop

### Week 10 — Agent Wallet & Machine Payment / 智能体钱包与机器支付
- [ ] [Agent Wallet](https://aiweb3.school/zh/handbook/bridge/agent-wallet/): What permissions can an agent hold, how to limit/revoke
- [ ] [Machine Payment](https://aiweb3.school/zh/handbook/bridge/machine-payment/): Micro-payments between machines
- [ ] [Agent Identity](https://aiweb3.school/zh/handbook/bridge/agent-identity/): How agents are identified, authorized, and traced
