# AI × Web3 School - Cohort 0 学习档案

## 关于本仓库

本仓库用于记录我在 **AI × Web3 School Cohort 0** 的学习过程。

**AI x Web3 School** 是一个面向 builders 的开源学习平台，系统学习 AI、区块链、智能合约、AI Agent 与去中心化 AI。 Handbook 把 AI 和 Web3 真正交叉时会遇到的问题拆清楚，帮助建立共同语言。

本仓库会记录：
- 📅 每日学习笔记（打卡草稿）
- 📝 任务进度与产出
- 🔬 实践实验与代码 demo
- 📖 Handbook 反馈（问题、建议）
- 🏆 黑客松项目

## 如何使用本仓库

### 每日学习流程

1. **早上 09:00** — 收到 cron 提醒，查看今日任务
2. **阅读 Handbook** — 按周计划阅读相关章节
3. **做实验/练习** — 在 `experiments/` 记录实践
4. **写每日笔记** — 更新 `daily/YYYY-MM-DD.md`
5. **晚间 21:00** — 收到打卡提醒，手动提交 WCB
6. **Git 记录** — push 到 GitHub

### 如何提交 Handbook 反馈

1. 在 Handbook 页面阅读时发现问题或建议
2. 在 `handbook-feedback/` 创建文件：`YYYY-MM-DD-章节名.md`
3. 使用[反馈模板](templates/handbook-feedback.md)格式填写
4. 可选：直接提 [PR 到官方仓库](https://github.com/lxdao-official/aiweb3school)
