**Date**: 2026-05-17
**Handbook Page**: [AI × Web3 School Handbook](https://aiweb3.school/zh/handbook/)

## Feedback / 反馈

### Positive / 做得好的地方

1. The Learning Agent prompt is very clear and well-structured — step-by-step initialization flow is easy to follow
2. The privacy and security reminders (no API keys, no PATs in public repos) are prominently placed
3. The 3-question profiling approach (2-3 questions at a time) respects user attention
4. Clear separation between Agent's role vs platform's role (WCB submissions are manual)

### Suggestion / 改进建议

**Suggestion 1**: The GitHub CLI installation could be a blocker for users in regions with slow GitHub release downloads. Consider adding a note about:
- Alternative: direct GitHub web repository creation
- Using GitHub API directly (no CLI needed)
- The download failure rate for `objects.githubusercontent.com` in certain network environments

**Suggestion 2**: The Learning Agent startup prompt mentions reading the WCB Learning page each day, but doesn't mention what to do if WCB is not yet accessible (e.g., before formal cohort start). Could add a "self-paced pre-cohort" path.

**Suggestion 3**: For the daily check-in, it would be helpful to have a concrete example of what a good check-in looks like, beyond the template.

### Clarification Needed / 需要澄清的地方

- Is the `handbook-feedback/` folder meant to track only one's personal feedback, or also aggregate community feedback? The prompt says "repo can be indexed and analyzed" — does that mean feedback is shared publicly as part of the learning proof?
